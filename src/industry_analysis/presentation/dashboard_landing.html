Industry analysis — open the UI

Port 8000 is this API. The React charts app runs on port 5173 while you develop (unless you build static files into web/dist/).

Step 1 — Keep this API running

uv run api (already running if you see this page).

Step 2 — Start the dashboard (dev)

In another terminal, from the repository root:

cd web
npm install
npm run dev

Then open:

Open charts UI (Vite — 127.0.0.1:5173)

If the page is blank, check the terminal: Vite may print a slightly different URL (e.g. localhost:5173).

Alternative — same server (after build)

No web/dist/ detected. Build once, then restart the API:

cd web
npm install
npm run build

Static UI is available on this server:

Open charts UI (/ui/)
